# CashBook Pro

## تشغيل المشروع على GitHub Pages
1. افتح مستودعك على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع (أو مجلد مستقل مثل `cashbook-pro/`).
3. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)` أو المجلد الذي رفعت إليه.
4. افتح رابط Pages الذي يظهر لك.

## الوظائف الحالية
- شاشة رئيسية عربية RTL ومتجاوبة.
- إنشاء دفتر مع الاسم والنوع والأيقونة واللون.
- رصيد افتتاحي وتاريخ بداية وميزانية شهرية ووصف.
- اختيار إظهار الدفتر في الملخص الرئيسي.
- إضافة دخل ومصروف وربطهما بدفتر.
- ملخص إجمالي الأرصدة وآخر الحركات.
- حفظ محلي على المتصفح باستخدام localStorage.
- Service Worker وPWA مبدئي.

## قاعدة البيانات
`database/schema.sql` مخطط أولي لقاعدة Cloudflare D1 المستقبلية. التطبيق الحالي لا يتصل بها بعد.

## مهم
النسخة الحالية MVP محلية وليست نسخة إنتاجية أو مزامنة سحابية. البيانات تبقى في المتصفح والجهاز نفسه؛ امسح بيانات الموقع قد يؤدي لفقدانها. أضف النسخ الاحتياطي والمزامنة قبل الاعتماد عليها مالياً.
